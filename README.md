# StudyMind

Aplicación web educativa desarrollada con PHP, MySQL, HTML, CSS y JavaScript.

## Instalación local
1. Copiar la carpeta `StudyMind` dentro de `C:\xampp\htdocs\`.
2. Iniciar Apache y MySQL desde XAMPP.
3. Abrir phpMyAdmin e importar `assets/database/studymind.sql`.
4. Revisar los datos de conexión en `assets/config/database.php`.
5. Abrir `http://localhost/StudyMind/`.

## Próximos pasos
- Crear una cuenta desde Registro.
- Agregar materias, temas y preguntas de cuestionarios.
- Completar las pruebas de acceso y resultados.

## Importante
La cuenta demo se crea con el script `assets/database/seed_demo.php`. Cambiar sus credenciales antes de cualquier despliegue público. Esta versión es para demostración local.
